# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

**Personal interview preparation library** — books, system design diagrams, and reference notes for software engineering interviews.

## File Naming Convention

All books follow: `Author - Title (Year).ext`

## Structure

| Directory | Content |
|-----------|---------|
| `books/system-design/` | System design interview books (DDIA, ByteByteGo, Grokking, Database Internals) |
| `books/coding/` | Coding interview prep (Cracking the Coding Interview) |
| `books/architecture/` | Software architecture (DDD, Code Simplicity, Beyond Vibe Coding) |
| `excalidraw/` | System design diagrams (Netflix, WhatsApp, Ticketmaster, etc.) |
| `notes/` | Reference notes and papers |

## GitHub Pages

Library page: `https://enkr1.github.io/interview_preparation_materials/`

## Adding New Books

1. Add file to correct `books/` subcategory
2. Update `index.html` — add entry under the right category
3. Commit & push
